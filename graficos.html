Canvas funcional

O Canvas é desenhado por JavaScript e contém um retângulo e um círculo.

Seu navegador não suporta o elemento Canvas.

SVG estilizado

O SVG contém um retângulo, um círculo e um polígono estilizados pelo CSS externo.

Canvas x SVG

O Canvas trabalha com pixels e é útil para desenhos dinâmicos. O SVG usa formas vetoriais e mantém a qualidade ao ser redimensionado.
